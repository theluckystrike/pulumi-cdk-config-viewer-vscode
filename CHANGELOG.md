# Changelog

## 0.1.0

- Initial release of Pulumi & AWS CDK Config Viewer for VS Code.
- Offline parser and visual inspector for `Pulumi.yaml`, `Pulumi.<stack>.yaml`, `cdk.json`, `cdk.context.json` and `*.template.json` CloudFormation templates.
- Free views for config keys and resources, stacks and context bindings, secrets and IAM audit, feature flags and outputs, and static findings.
- Pro tools (1 free try each): Markdown security audit, config diff, and Markdown/CSV resource and config inventory export.
